# Antworten für ABI (zum Kopieren in den Postkorb oder Telegram)

Freigabe für genau einen Stand:
> OK für Stand <Commit> auf Branch <Branch>: Push, Pull Request erstellen und Squash-Merge in main. Danach Ergebnis prüfen und Commit-Hash melden.

Nur hochladen, nicht mergen:
> OK nur für Push von <Branch> (Commit <Commit>) und Pull Request als Entwurf. Kein Merge.

Ablehnen / nachbessern:
> Kein OK. Bitte zuerst: <was fehlt>. Danach neuer Bericht.

Nächstes Arbeitspaket starten:
> Bitte beginnt mit Arbeitspaket <Name>. Entwickeln und testen, dann Freigabebericht. Nichts veröffentlichen.
